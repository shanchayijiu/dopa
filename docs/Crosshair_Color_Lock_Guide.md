# 准星找色功能使用指南 (Crosshair Color Lock Guide)

本指南将帮助您配置和优化“准星找色”功能，以实现稳定、精准的目标锁定。

“准星找色”通过识别屏幕中心区域的特定颜色，自动将游戏准星吸附到辅助准星。

## 2. 快速上手

1.  **开启功能**：勾选 `准星找色` -> `启用准星找色`。
2.  **进入取色模式**：
    *   点击 `添加颜色` 按钮。
    *   将游戏准星对准您想要锁定的目标颜色（例如敌人的红色身体）。
    *   按下键盘上的 **`F3`** 键。
    *   系统会自动采集颜色并生成配置。
3.  **调试验证**：
    *   勾选 `显示过滤效果`。
    *   观察预览框：背景应为全黑，只有您想要的目标显示为原色，且中心有一个**蓝点**。
    *   如果出现了不想要且带有颜色的背景杂点，请调整容差。

## 3. 常见问题解决

### Q1: 红色目标被识别成蓝色？或者什么颜色都吸？
**原因**：颜色的 **容差（Tolerance）** 设置过大，导致颜色范围覆盖了全色域。
**解决**：
1.  勾选 `仅预览当前颜色`，单独排查是哪个颜色组出了问题。
2.  减小 **`H 容差`**（色相）：这是最关键的参数。通常 `5~15` 是比较精准的范围。如果设得太大（如 >40），就会把不同颜色混在一起。
3.  减小 **`S 容差`**（饱和度）和 **`V 容差`**（亮度）：防止把背景的灰色/白色误识别进来。

### Q2: 屏幕晃动或移动时识别不稳定？
**原因**：游戏画面在移动时会产生“动态模糊”，导致目标颜色的边缘变虚、颜色变淡（饱和度 S 降低）。
**解决**：
1.  **降低 `S Min` (最小饱和度)**：允许识别颜色更淡的目标。例如从 100 降到 50。
2.  **增大 `H 容差`**：稍微增加一点（例如从 5 增加到 10），以容忍变色。
3.  **游戏设置**：强烈建议在游戏画质设置中**关闭“动态模糊” (Motion Blur)**，这能显著提高识别稳定性。
4.  **调整 `最小面积`**：如果晃动导致目标变碎，尝试减小最小面积（如调至 0.5）。

### Q3: 预览框里有目标，但没有绿框（不锁定）？
**原因**：目标虽然被过滤出来了，但不符合形状或面积要求。
**解决**：
1.  **检查 `最小/最大面积`**：目标可能太小或太大了。
2.  **检查形状**：程序默认过滤掉长条形（长宽比 < 0.5 或 > 2.0）的物体。如果您的目标是细长条，这会导致不识别。
    *   *注：当前版本已内置此逻辑，如需修改需联系开发者。*

## 4. 参数详细说明

### 基础参数
*   **H 容差 (Hue)**：**最重要**。决定颜色的种类范围。红色/蓝色/绿色靠这个区分。
    *   *调小*：颜色区分更准，不易误识别。
    *   *调大*：适应性更强，但容易吸错人。
*   **S 容差 (Saturation)**：颜色的鲜艳程度。
    *   *S Min*：设得越低，越能识别灰蒙蒙的颜色（但也容易把背景灰墙识别进来）。
    *   *S Max*：通常保持 255。
*   **V 容差 (Value)**：颜色的明暗程度。
    *   *V Min*：设得越低，越能识别黑暗中的目标。

### 过滤参数
*   **最小面积**：小于此像素数量的目标会被忽略。用于过滤噪点（如远处的小火花）。建议 `1.0 ~ 5.0`。
*   **最大面积**：大于此像素数量的目标会被忽略。用于过滤大片背景（如红色的墙壁）。
*   **检测区域宽/高**：屏幕中心多大范围内进行找色。建议 `100 ~ 300`。太大影响性能，太小容易跟丢。

### 控制参数
*   **回拉强度**：准星移动的平滑度。`0.1` 较慢，`0.5` 很快。
*   **仅瞄准时启用**：**强烈推荐勾选**。只有按下右键（瞄准）时才工作，防止走路时乱晃。

---
**调试技巧总结**：
遇到问题，先开 **`显示过滤效果`** 和 **`仅预览当前颜色`**，盯着那个小黑框看，直到黑框里只剩下纯净的目标，再进行实战。
